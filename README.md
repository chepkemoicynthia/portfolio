# Portfolio Starter

This is a simple personal portfolio website built with plain HTML, CSS, and JavaScript.

## Open locally

You can open `index.html` directly in a browser, or run a local server:

```bash
cd c:/xampp/htdocs/portfolio
python -m http.server 8000
```

Then visit http://localhost:8000

## Customize

- Update the personal info in `index.html`
- Change the color theme and layout in `styles.css`
- Replace the placeholder project details and contact info with your own
- Add your real social links, project URLs, and email
